# Hermes frontend

React + TypeScript SPA (Vite), deployed to GitHub Pages. See the [repo root README](../README.md) for the full project overview, local setup, and deployment instructions.

Quick reference:

```bash
npm install
npm run dev        # http://localhost:5173/hermes/, talks to .env.development's API URL
npm run build       # production build to dist/, using .env.production's API URL
npm run lint         # oxlint
npx tsc -b --noEmit   # type-check
```
